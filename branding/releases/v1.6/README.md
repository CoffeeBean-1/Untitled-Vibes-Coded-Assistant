# CAi corrected visual assets - v1.6

The selected second-board concept #10 and approved two-line tagline are retained. This release repairs the transparency mask; it does not introduce a new logo.

For white/light backgrounds use assets/cai-logo-light.svg or cai-logo-light@2x.png (dark lettering). For dark backgrounds use cai-logo-dark.svg or cai-logo-dark@2x.png (white lettering). For the symbol alone use cai-mark-128.png, cai-mark-256.png or cai-mark-512.png. Both the exterior and central opening are transparent. No dark badge is necessary on plain white.

The original source is a small raster crop. Larger PNGs are resamples; color SVGs embed raster artwork plus vector lettering. The selected source colors are retained away from a narrow antialias repair band. Installed/favicons and standalone wordmarks are unchanged. Preview checkerboards are not embedded in PNG assets.

Use the complete digital-assistant-codex-handoff-v1.6.zip for Codex migration instructions, source provenance, current brand policy and validation evidence. Keep user logo overrides and all application data. No font binaries are included.
